DMGT: Set Theory Equivalence Partitions

Universal Set U = Listings partitioned by district zone equivalence relation:

• Relation: (l_a, l_b) ∈ R ⇔ l_a.zone_id = l_b.zone_id
• Equivalence Class: [Z_i] = { l ∈ U | l.zone_id = Z_i }
• Disjoint Union: ∪ [Z_i] = U and [Z_i] ∩ [Z_j] = ∅ (∀ i ≠ j)

ADSA: Dijkstra Shortest Highway Transit

Weighted Graph G = (V, E, W) using Min-Heap PriorityQueue:

• Vertices |V|: APMC District Mandis
• Edge Weights W(u, v): Freight in ₹/Quintal
• Complexity: O((|V| + |E|) log |V|)
• Landed Cost = Farmer Price + Dijkstra Transit
